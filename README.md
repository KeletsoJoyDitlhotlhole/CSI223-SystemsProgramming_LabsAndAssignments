# 🖥️ Systems Programming
## CSI223-Systems Programming Labs by Keletso Joy Ditlhotlhole

A collection of assignments and laboratory exercises completed as part of my **Systems Programming (CSI 223)** course during my BSc Computer Science studies. 🎓💻

## 🌸 About This Repository

This repository documents some of my practical work in **Systems Programming**, with a strong focus on working within Unix/Linux environments, Bash shell programming, regular expressions, command-line utilities, text processing, and scripting.

The coursework consisted of several laboratory exercises and assignments designed to develop practical experience using system-level tools and solving problems from the command line.

Rather than simply learning commands individually, the exercises involved combining different shell utilities, regular expressions, pipes, and input/output operations to solve specific problems.


## 🛠️ Technologies & Concepts

- 🐚 **Bash / Shell Scripting**
- 🐧 **Unix/Linux Environment**
- 🔍 **Regular Expressions (Regex)**
- 🔎 **grep / grep -E / egrep**
- 📄 **Text & File Processing**
- 🔗 **Pipes & I/O Redirection**
- 📝 **Perl**
- ⚙️ **Command-Line Utilities**
- 🧠 **Pattern Matching & Problem Solving**
